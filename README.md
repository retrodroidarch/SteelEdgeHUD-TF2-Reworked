# SteelEdgeHUD-TF2-Reworked
A competitive TF2 HUD built for clarity, performance, and tactical awareness.
---

## Features

- Large, centered health and ammo indicators  
- Clean killfeed with team-colored text  
- Compact scoreboard and minimal menus  
- Transparent viewmodels for better visibility  
- Optimized for high FPS and low clutter  
- Custom crosshairs and Uber meter placement

---

##  Installation

1. Click the green **Code** button → **Download ZIP**  
2. Extract the ZIP file  
3. Move the folder named `toonhud.zip` into:  
Steam\steamapps\common\Team Fortress 2\tf\custom
---
4. Launch TF2 and enjoy your new HUD!
